# 楠團銀行：虛擬點數

銀行入口為 `#bank`，桌機左側、頁首錢包與補給頁均可進入。手機保留五個底部導覽；原玩家轉帳維持 `#wallet`，兩頁互相連結。

| 項目 | 首次安裝預設 |
| --- | --- |
| 活期存款 | 日息 0.5%、隨時存提 |
| 計息 | 按本金及持有秒數的單利；未領利息不複利 |
| 領息 | 滿 1 點可領入錢包，零頭繼續累積 |
| 貸款 | 日息 1.5%、每人同時一筆、上限 3,000 點、7 天到期 |
| 還款 | 可提前／分次，先還利息再還本金 |
| 全部還清 | 依伺服器收到操作時的欠款結清，重送沿用回執 |
| 取整 | 還款時不足 1 點的貸款利息以 1 點計，取整也消耗利息上限 |
| 逾期 | 未清不能再借，不自動扣錢包或桌上籌碼 |
| 利息上限 | 累積貸款利息最多原借本金，不另收逾期罰款 |

例：存 1,000 點完整一天可領 5 點；借 1,000 點完整一天利息 15 點，7 天一次還款共 1,105 點。部分還本後依剩餘本金計息。

總資產＝錢包＋桌上與底池＋銀行存款－貸款本金與應付利息。待領存款利息領入錢包後才列入資產。存提款、借款及還本金不列入獲利或資金流；存款利息收入與實付貸款利息影響資金變化，不列入遊戲淨輸贏。排行、個人資金圖與後台統計沿用同一定義。

## 管理員

「管理後台 → 遊戲設定 → 銀行設定」可調存款日息 0–5%、新貸款日息 0–10%、每人新貸款上限 0–1,000,000 點及期限 1–30 天。存款利率不可高於貸款利率；上限 0 暫停新借款。每次填備註並稽核操作者、前後設定與時間。

改存款利率前先結算舊利率累積，再從修改時刻套新利率；已借出貸款保留原利率、原本金與到期時間。借款確認鎖住當時版本，中途改條件會要求重新確認。初始化不覆寫已有設定。

## 實作與資料

- [bank.py](../bank.py)：整數計息、存貸、私有明細與設定稽核。
- [wallet.py](../wallet.py)：錢包可用餘額與含銀行的總資產。
- [bank.js](../static/bank.js)：玩家櫃台與後台設定，沿用既有樣式、CSP。
- 既有 SQLite 新增 `bank_settings`、`bank_accounts`、`bank_loans`、`bank_ledger`、`bank_operations`、`bank_settings_history`，隨原資料備份。

計息用整數秒與 `86400 × 10000` 分母，避免浮點誤差。查詢僅投影、不寫入，沒有銀行背景寫入迴圈。交易共用現有寫入序列與 savepoint，錢包、銀行、明細、資金事件及回執一併提交／回滾；同帳號操作編號重送不重複扣點，不同內容回 409。前端送出前存回執，重載可核對原操作，無法保存就不送出。

`GET /api/bank` 只回本人資料，`before` 分頁最多 30 筆。`POST /api/bank/{deposit,withdraw,collect,borrow,repay}` 執行交易。`GET/POST /api/admin/bank-settings` 檢查管理員與首次改密碼要求。全部沿用登入、帳號狀態、CSRF 與 no-store。沒有真實金流。
