# 楠團漁港：固定參考版

畫面與釣魚回合分別固定對照 Fishing Clash 與 QY Games《黃金捕魚場 Online》。公開參考、觀察與設計差異見[固定參考對照](design-proposals/fishing-golden-carnival.md)。未公開的原廠內部數值不宣稱相同；本站使用原創美術與公開點數規則。

## 休閒釣魚

第一人稱水面，前景釣竿。選魚餌→拋竿→咬鉤提竿→控制張力→魚獲特寫，主要按鈕始終在舞台右下；圖鑑與設定改由面板開啟。

- 每日精力預設20，台灣午夜重置。八種魚餌對應魚種，前3種耗1、中間3種耗2、末2種耗3精力。
- 魚餌入水0.8秒咬鉤，3.2秒內提竿。按鍵模式按住收線、放開鬆線；滑桿模式按住滑動以改變收線力道。過高斷線、過低脫鉤；中央增加Combo，影響魚獲分數與星等。
- 以50ms固定步長由伺服器模擬，失聯1.1秒視為放開；30秒內沒完成也會失敗。三種釣竿沿用寬區／速度取捨，魚線安全範圍和收線速度不同。
- 成功直接入帳該魚公開價值，不再要求另外出售；魚種、尺寸、分數、星等會在結果畫面顯示。「再拋一竿」直接開下一竿；收線放開不會多觸發一次。
- 更新前的經典控魚竿仍依原規則完成並進魚簍；魚簍既有庫存仍可出售。

## 街機捕魚

六房，每房四席；砲台沿四角配置，共用18隻魚與成隊軌跡。桌機橫向魚場、窄手機轉為直向魚場座標，魚體維持比例，點按轉換與伺服器座標一致。

- 瞄準並按住魚場／發射鍵，放開停止；鎖定、自動、冰凍與魚種選擇各有獨立按鈕。三種魚炮間隔0.24／0.18／0.34秒、網半徑15／10／27。
- 砲彈10／100／1,000點，對應1／10／100份攻擊，並受管理員上限限制。砲彈以1150世界單位／秒飛行，壽命1.1秒；碰到第一隻魚才逐份攻擊抽捕獲，落空仍扣點。一次批次最多4發、每發token唯一。
- 八種一般魚含本金倍率2／3／5／8／12／20／35／60。特殊魚基本倍率：黃金蟹80、章魚90、電鰻100、海龍120，約每兩分鐘輪替出場。
- 特殊魚捕獲時，伺服器依當時魚位挑選範圍內最多8／4／5／8尾一般魚；每隻魚都建立唯一捕獲紀錄，分別呈現捕網、觸手、雷霆或爆破連鎖，結算一起入帳。
- 每份攻擊成本10點，命中後獨立成功率＝派彩基準／本次總魚種倍率。攻擊份數N=每發點數÷10，至少捕獲一次機率=1−(1−基準/總倍率)^N。重擊數H為成功攻擊份數，總返還=10×總倍率×H；至少一份成功才捕獲該魚一次。預設基準95%，精確條件期望=每發點數×95%，落空會降低整體返還。一般魚只計自身，特殊魚含連鎖總倍率；沒有個人輸贏補中或隱藏血量。
- 新增金甲龜25倍、獵鯊80倍；人魚動態200／300／400／500／600倍，鯨王300／475／650／825／1,000倍。特殊魚顯示當場倍率，連鎖另計。
- 冰凍2秒／冷卻30秒，不能重疊；雷射6秒／冷卻45秒，彈速1800、捕網半徑加12，逐發仍扣點且不增加免費攻擊。技能各自冷卻，換房不重置。失聯40秒釋位，退出座位後可觀戰。

## 協定、恢復與驗證

新操作 `gameplay_version=4`；個人快照用 `GET /api/fishing?version=4`，控魚快照用 `/api/fishing/skill-state?version=4`。舊畫面讀取個人快照會收到426更新提示；舊版新操作不扣點，已完成v2／v3操作仍可用原完整指紋重送。資料庫竿紀錄version=2與公開通訊版本不同，`mechanic=tension`區分新控魚；version=1舊可領竿保留。

`burst`成功回應的state為`partial=true`增量，只有wallet、shots／spent／returned與server_time；前端合併既有完整狀態。重送原操作仍可取得完整目前狀態。

已接受舊砲彈沒有power欄位，沿用原始stake×倍率結算；升級不把它們當作新重擊。六人四房座位改成四人六房時，保留原0–3座，將4–5座安全移到空位，共24席；冷卻與已付款砲彈保留。

所有寫入經 FIFO／SQLite交易。錢包操作以帳號＋operation_id保存指紋；重送只重播原回執。捕獲按碰撞時間／砲彈ID排序，同魚只有一筆capture。連鎖只記一筆錢包總派彩，為每尾魚建立關聯的零成本效果事件，不增加付費發數。派彩失敗整次回滾，保留已付款砲彈以便恢復。

推播分流與背壓沿用：魚場5Hz共用快照，客戶端補間；Canvas30fps、減少動態20fps，手機DPR上限1.5。慢回應或背景停射並丟棄未送出砲彈，回來不自動續射。已接受的砲彈仍完成結算。
