# 楠團漁港：固定參考版

畫面與釣魚回合分別固定對照 Fishing Clash 與 QY Games《黃金捕魚場 Online》。公開參考、觀察與設計差異見[固定參考對照](design-proposals/fishing-golden-carnival.md)。未公開的原廠內部數值不宣稱相同；本站使用原創美術與公開點數規則。

## 休閒釣魚

第一人稱水面，前景釣竿。選魚餌→拋竿→咬鉤提竿→控制張力→魚獲特寫，主要按鈕始終在舞台右下；圖鑑與設定改由面板開啟。

- 每日精力預設20，台灣午夜重置。八種魚餌對應魚種，前3種耗1、中間3種耗2、末2種耗3精力。
- 魚餌入水0.8秒咬鉤，3.2秒內提竿。按鍵模式按住收線、放開鬆線；滑桿模式按住滑動以改變收線力道。過高斷線、過低脫鉤；中央增加Combo，影響魚獲分數與星等。
- 以50ms固定步長由伺服器模擬，失聯1.1秒視為放開；30秒內沒完成也會失敗。三種釣竿沿用寬區／速度取捨，魚線安全範圍和收線速度不同。
- 成功直接入帳該魚公開價值，不再要求另外出售；魚種、尺寸、分數、星等會在結果畫面顯示。「再拋一竿」直接開下一竿；收線放開不會多觸發一次。
- 更新前的經典控魚竿仍依原規則完成並進魚簍；魚簍既有庫存仍可出售。

## 街機捕魚

六房，每房四席；砲台沿四角配置，共用18隻魚與成隊軌跡。桌機橫向魚場、窄手機以直向操作區呈現，不再把魚場旋轉90度，魚體維持比例，點按轉換與伺服器座標一致。

- 瞄準並按住魚場／發射鍵，放開停止；鎖定、自動、冰凍與魚種選擇各有獨立按鈕。三種魚炮間隔0.24／0.18／0.34秒、網半徑15／10／27。
- 每發炮價10／100／1,000點，受管理員上限限制。普通捕獲返還＝射出時炮價×魚種倍率；100點炮捕到20倍魚，基本返還2,000點。炮價同步放大成本與魚價，不增加隱藏抽取次數。三檔砲彈分別1150／1400／1650世界單位／秒，捕網半徑另加0／6／12、壽命1.1秒，碰到第一隻魚才判定，落空仍扣點；每批最多4發，token唯一。
- 八種一般魚含本金倍率2／3／5／8／12／20／35／60。特殊魚基本倍率：黃金蟹80、章魚90、電鰻100、海龍120，每房每兩分鐘出場，六房各有不同主要Boss；海龍每4秒加30倍，最多240倍。
- 特殊魚捕獲時，伺服器依當時魚位挑選範圍內最多8／4／5／8尾一般魚；每隻魚都建立唯一捕獲紀錄，分別呈現捕網、觸手、雷霆或爆破連鎖，結算一起入帳。
- 新炮彈`pricing=cannon-v1`。命中後一次捕獲判定：p＝派彩基準÷本次總返還倍率期望值。普通／連鎖總倍率為M，寶藏次數K，每次均值6.31倍，因此p＝target_bps×100／[10000×(100M＋631K)]；成功基本返還stake×M，另開寶藏。全部寶藏領取後精確條件點數期望為stake×target_bps/10000，預設95%；落空降低整體返還，道具不折算點數。沒有依玩家輸贏調整、隱藏血量或宣稱與原廠內部機率一致。
- 新增金甲龜25倍、獵鯊80倍；人魚動態200／300／400／500／600倍，鯨王300／475／650／825／1,000倍。動態Boss每4秒升一檔，捕獲時鎖定當時倍率，特殊魚顯示當場倍率。人魚與鯨王改觸發獨立寶藏，其他四種Boss保留連鎖。
- 初次入場一次發給5個冰凍、2個雷射；技能使用耗1個，重入／重送不重發。寶藏另贈1個隨機技能道具。冰凍2秒／冷卻30秒，不能重疊；雷射6秒／冷卻45秒，彈速為max(1800, 該炮價彈速+350)、捕網半徑再加12，命中普通魚可沿光束連鎖最多3尾一般魚，所有目標倍率合併驗算，逐發仍扣點且不增加免費攻擊。技能各自冷卻，換房不重置。失聯40秒釋位；返回會嘗試重入原房，滿房可另選。主動觀戰則保留觀戰，主操作鍵可重新入座。

## 海底寶藏（本站規則）

魚場會出現20倍寶箱；捕獲寶箱／人魚有3次獎勵，鯨王5次。每次倍率2、3、5、8、10、20、50、100，權重30、25、20、12、7、4、1、1（合計100）；平均6.31倍。每次獎勵乘觸發時炮價，與基本捕獲分開入帳。這套表是本站選定的公開規則，原作未公開同一張表。

伺服器為捕獲者建立`fishing_bonus_events`，保存炮價、次數、池／權重版本快照。`POST /api/fishing/bonus`需`bonus_id`和不可變operation_id；擁有人開啟後，用安全亂數產生全部獎勵，派彩、技能庫存與狀態一起提交。相同或不同operation_id重開同一事件，都只能領一次。ready事件及最後一個settled事件放在本人私有快照，公共魚場不帶未來結果。動畫只揭示已確認結果，可略過、關閉或重進；待領達10個時先開箱再發射（已接受批次仍會全部結算）。

`fishing_items`保存技能庫存，不會因換房補滿。點數、遊戲規則和判定在伺服器，五格邊框獎勵盤由`fishing-bonus.js`呈現；關閉動畫不改結果。

## 協定、恢復與驗證

新操作 `gameplay_version=6`；個人快照用 `GET /api/fishing?version=6`，控魚快照用 `/api/fishing/skill-state?version=6`。舊畫面讀取個人快照會收到426更新提示；舊版新操作不扣點，已完成v2／v3／v4／v5操作仍可用原完整指紋重送。資料庫竿紀錄version=2與公開通訊版本不同，`mechanic=tension`區分新控魚；version=1舊可領竿保留。

`burst`成功回應的state為`partial=true`增量，只有wallet、shots／spent／returned與server_time；前端合併既有完整狀態。重送原操作仍可取得完整目前狀態。

已接受v3及以前砲彈沒有power欄位，維持stake×倍率；v4含power但沒有pricing，維持10點多試次規則。v5／v6必須有pricing快照，不能由目前前端檔位覆寫舊結果。六人四房遷移到四人六房的24個位置及既有冷卻均保留。

所有寫入經 FIFO／SQLite交易。錢包操作以帳號＋operation_id保存指紋；重送只重播原回執。捕獲按碰撞時間／砲彈ID排序，同魚只有一筆capture。連鎖只記一筆錢包總派彩，為每尾魚建立關聯的零成本效果事件，不增加付費發數。派彩失敗整次回滾，保留已付款砲彈以便恢復。

推播分流與背壓沿用：魚場5Hz共用快照，客戶端補間；Canvas30fps、減少動態20fps，手機DPR上限1.5。慢回應或背景停射並丟棄未送出砲彈，回來不自動續射。魚場超過6秒無有效world事件即主動關閉舊流，以0.3至4.8秒退避重建；generation隔離舊訊息，重連不重送新扣款。已接受的砲彈仍完成結算。

[規則與並行測試](../tests/python/test_fishing.py)、[瀏覽器操作測試](../tests/browser/fishing.cjs)、[可重現負載量測](../scripts/bench-fishing.py)均使用隔離資料庫與合成帳號。

美術：街機16種生物各有6格游動圖，依當場魚種逐張載入16張獨立WebP圖集，每張使用完整魚體的自適應來源框，移除舊四張游動圖集，未載入不退回舊圖。魚體比例／轉向和伺服器橢圓命中範圍共用[幾何資料](../static/fishing-art.json)，凍結期間轉向與位移一起停止。保留休閒模式的原素材。炮台旁集中錢包、炮價、技能數量和寶藏入口；原生全螢幕入口在漁港選單。參考證據與數值界線見[實玩核對](design-proposals/fishing-reference-audit-20261026.md)。


## v6視覺與機率核對

六房使用三種海底場景與不同魚群／Boss；游動為每種六姿勢、每秒八格，跟隨行進方向，命中閃光、展網、雷射穿透、金幣飛回對應玩家炮台。Canvas仍維持30／20fps與DPR上限。高價炮增加命中範圍與彈速，命中後仍是一次機率判定，沒有隱藏累積血量。不同炮價直接放大捕獲金額，不能保證提高單發收益或追回損失。

## 完整遊玩循環與個人戰報

魚場右下「戰報與補給」與漁港選單共用同一個面板；開啟會安全停射。每天可免費領冰凍3個、雷射1個，依伺服器台灣午夜換日，未領不累積；初次入場原有5／2個道具繼續保留。領取不扣錢包、不修改魚的捕獲率；道具仍依原技能效果及冷卻使用。寶藏仍額外贈送隨機技能。

`POST /api/fishing/supply`沿用通訊v6、不可變operation_id與FIFO交易；`fishing_supplies`以帳號＋日期唯一。不同操作編號同日領取不重發，相同編號跨日重送仍只重播原次回執，需新操作領新一天。補給紀錄、庫存和回執同一savepoint，任何失敗一起回滾。每日補給狀態只在本人完整快照提供，發射partial回應和公共SSE不額外攜帶戰報。

本人戰報列出最多12筆近期已結算的付費炮彈，區分落空／命中未捕獲／捕獲，顯示炮價、基本與連鎖返還、淨額及寶藏另計提示。後端以`fishing_projectile_owner(user_id,id DESC)`最多讀48筆事件再排除飛行中與零成本連鎖，避免每次完整快照掃全表；大量連鎖時可能少於12筆。累計炮彈花費／已入帳返還包含已領寶藏，與休閒收益、轉帳及錢包補給分開；未結算炮彈仍有後續派彩，這個淨額不是最終結算或理論RTP。

開啟房間選單重新讀取人數；切房確認成功才更換魚場，滿房可直接觀戰，觀戰不自動搶座。未知原次扣點尚待確認時，暫停模式切換與換房。長面板的關閉鈕固定在頂部；開箱延遲回應只更新相同寶箱，不覆蓋使用者另開的寶箱，離開頁面不重開動畫。
