# 楠團漁港玩法與協定

## 技巧垂釣

- 每帳號同時一竿；每日精力預設20，台灣午夜重置。管理員可調整每日精力。
- 拋竿力道0–333近岸耗1、334–666中距耗2、667–1000遠投耗3。遠投提高稀有魚權重，圖鑑公開各距離遇魚率。
- 等待2–4.5秒咬鉤，3.2秒內提竿。進入收線後，按住使控制區上升、放開下降；魚在區內增加進度、區外降低進度並累積逃脫。23秒內未完成或逃脫滿格則失敗，精力不退還。
- 三款免費釣竿：平衡（區寬30%、速度1×）、寬區慢收（37%、0.8×）、窄區快收（25%、1.25×）。選擇於下次拋竿生效。免費漁獲可整簍出售，圖鑑保留。
- 離頁仍會判定，無自動收魚；更新前已拋出的舊竿保留原可領取獎勵。

## 多人共享魚場

- 四房，每房六席；沒有席位可觀看，開火須入場。同場看到相同魚隻和捕獲結果。離線40秒自動釋位。
- 按住魚場瞄準或按住發射鍵連發，放開停止；另有明確的自動連發開關。點選魚體可追蹤該隻魚，點魚種卡可鎖定目前的一隻同種魚。目標離開或被捕獲即停射。
- 平衡炮每0.24秒一發、網半徑15；快炮0.18秒／半徑10；大網炮0.34秒／半徑27。所有炮彈世界速度1150單位／秒，壽命1.1秒，最多每發100點並受管理員共用上限限制。
- 實際飛行碰到第一隻魚才判定捕獲；落空、命中但沒捕獲都消耗該發點數。沒有隱藏血量、個人機率或補中機制。成功捕獲總返還＝該發點數×魚倍率，直接進錢包，不再加可售魚。
- 八種魚倍率2／3／5／8／12／20／35／60。命中魚體後捕獲率＝管理員派彩基準÷倍率；預設基準95%，故例如2倍魚為47.5%。這是命中後條件平均，整體返還受落空與競爭影響。
- 約每兩分鐘巨獸來襲：旗魚變為70倍、體型放大，捕獲率依70倍重算。共用冰凍持續2秒，帳號冷卻30秒；不能重疊、換房不重置。

## 安全恢復與測試

所有寫入經 FIFO／SQLite交易。錢包操作以帳號＋operation_id保存完整指紋，同內容重送重播原回執；改內容會拒絕。每發token唯一，同魚capture唯一；伺服器按碰撞時間／砲彈ID處理競爭，無重複派彩。發射時間僅允許有限延遲補償，不能追溯搶走已結算的魚。

新版端點：`cast`、`hook`、`input`、`gear`、`join`、`leave`、`heartbeat`、`burst`、`skill`；出售仍用`sell`。`GET /api/fishing`為個人狀態；`skill-state`為個人控魚同步；`world?room=1`與`events?room=1&client=...`僅含共享世界，沒有錢包、私人竿或未來隨機票。

網路慢時限制待送數量並停止續發，不會追補大量炮彈；已接受的炮彈仍會結算。手機切回／重新連線要先同步，不自動續射。重複送出同批次不再次扣款。
