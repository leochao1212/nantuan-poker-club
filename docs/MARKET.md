# 點數交易所

本功能是遊戲內點數的現貨模擬交易，不連券商、不會購入真實證券或貨幣。入口：首頁「股票／加密貨幣」、銀行頁同名按鈕，或 `/#market`。銀行在電腦側欄、手機頂部文字按鈕與首頁顯示。

## 第一版市場與免費資料

| 市場 | 標的 | 來源／更新 | 成交方式 |
| --- | --- | --- | --- |
| 台股 | 台積電、鴻海、聯發科、0050、0056 | [TWSE OpenAPI](https://openapi.twse.com.tw/) 每日收盤 | 委託之後的新收盤資料 |
| 美股 | AAPL、MSFT、NVDA | [Marketstack Free](https://marketstack.com/pricing)，需私密 API Key、每日收盤、每月 100 requests、限非商業使用 | 委託之後的新收盤資料；尚未提供 Key 時停用 |
| 加密貨幣 | BTC、ETH、SOL | [Kraken 公開 Ticker](https://docs.kraken.com/api-reference/market-data/get-ticker-information)，背景約每 10 秒 | 取得下一筆新觀測的買價／賣價 |
| 匯率 | USD → TWD | [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free)，每日更新、頁面署名 | 轉換美元行情為台幣點數 |

台股資料集的[授權與每日更新說明](https://data.gov.tw/dataset/11549)採[政府資料開放授權條款第 1 版](https://data.gov.tw/license)。只轉換本程式所用報價，不代理或輸出完整 FX 資料集。Marketstack 免費方案額度為每個 symbol 各一 request；三檔每日一批最多 93 requests / 31 天，失敗也等待 24 小時，避免無限重試耗盡配額。缺 Key 每小時檢查一次，不對美股供應商送請求。正式服務若轉為商業使用須重新檢查供應商方案。

這一版股票是**每日收盤模式**，不是即時或十五分鐘延遲撮合。來源時間、原幣、匯率時間都會顯示。休市或來源未更新時繼續等候，重新下載同一收盤日期不會被當成新價格。美股供應商只帶 session date 時以該日期 00:00 UTC 做保守比較，因此某些當日委託會延到下一交易日收盤成交，不推算未提供的盤中成交價。

## 點數與委託契約

- 1 點＝1 元台幣，現貨、小數份額最多八位，不可放空、不開槓桿。
- 買入先保留整數點數預算；取得下一筆來源時間晚於委託時間的有效行情後，依 ask 換算份額。買入成本向上取整、不超過預算，多餘點數退回。
- 賣出保留既有份額，下一筆有效 bid 成交，所得向下取整。各筆取整誤差不到一點；第一版無額外手續費。市值不足一點或超出單筆 10^12 點上限的賣單取消，不吞掉份額。
- 不拿客戶端價格成交。`POST /api/market/order` 只接受 symbol、side、amount／quantity、operation_id；伺服器決定報價與成交。
- 同一帳號最多 20 筆待成交；買單最多一百萬點。股票七天、加密貨幣兩分鐘到期。可隨時取消，取消／到期買單原額退回，賣單解除份額保留。
- 報價異常或過期停止新委託與成交。加密行情最多 120 秒、匯率最多 72 小時；股票容許週末等七天資料年齡，但仍必須取得晚於委託的來源時間才能成交。
- 股票單次價差超過 35% 時凍結舊估值與交易，避免尚未處理的分割被當成巨大盈利；第一版不派股息、不自動調整分割股數。凍結須由維運核對公司行動後處理，不能直接讓使用者用新價套現。未發佈完整企業行動支援前保持精選標的範圍。
- 錢包、保留預算、持倉、成交、退款與回執共用同一 SQLite 交易／WriteQueue。重送相同回執返回同一委託；同編號不同內容回 409。瀏覽器先保存回執，結果不明可重新確認，換頁／重新整理也保留。
- 只有本人可看自己的委託與持倉；API 登入與 CSRF 規則沿用現有系統。封鎖／刪除帳號的待成交委託取消，不再執行交易。

總資產＝錢包＋桌上與底池＋銀行存款－貸款＋持倉的最後已知估值＋買單保留預算。行情過期保留舊估值並標示，不會忽然歸零。行情標記損益與成交取整差額合併成每小時一筆 `market_value`，影響資金圖但不算補給入帳或牌局輸贏。

## 私密設定與運行

開關為 `POKER_MARKET_DATA=1`（正式預設），離線測試為 `0`。選填 `POKER_MARKETSTACK_KEY` 只放在伺服器私有環境檔；不要放 Git、PR、聊天、前端或截圖。

本機 Docker 使用 `.env` 配合 [docker-compose.yml](../docker-compose.yml) 的 environment。正式服務由既有私有 Compose 管理，維運需在正式 Compose 的 environment／env_file **明確傳入**同名變數，重建容器後生效；只在宿主機 `.env` 新增變數而未傳給容器不會生效。尚未設定時美股顯示待啟用，其他市場可用。此 PR 不改動既有受限部署閘道或取得主機額外權限。

單一背景工作抓行情，最多三個並行、8 秒 timeout、2 MB 上限，網路請求時不持有 DB 交易或 WriteQueue。快取存資料庫，重新啟動不重置 API 呼叫配額時鐘。報價更新不向每張牌桌廣播；只有成交／退款觸發原有錢包推播。交易頁顯示時每十秒讀自己的持倉與行情，背景分頁暫停，回前景與網路恢復時立即重讀。估值沿用 `view_cache` 的三表版本失效，避免大廳每人重算。

## 驗證

`python -m unittest tests.python.test_market -v`：新觀測才成交、資產守恆、份額／取整、凍結異常、過期退款、封鎖取消、HTTP 並行去重、私有資料隔離、來源格式／錯誤不漏 Key。

`npm run test:market`：隔離資料庫，Chromium／WebKit 手機及電腦、銀行入口、買賣、丟失回應後重新整理確認、舊 GET 不能蓋掉成功 POST、24 組 viewport／觸控遮擋檢查。所有報價與帳號均為測試資料，不操作正式點數。
