# 點數交易所

使用遊戲內點數的模擬市場，不連券商、不購入真實證券或貨幣。桌面左欄與手機底部均有「點數交易」入口，銀行也可直接前往 `/#market`。手機底部維持五個入口：大廳、成員、交易、會所、補給；排行仍可從成員頁開啟，銀行在頂部文字按鈕。

## 搜尋、原幣報價與合約預設

交易頁現在預設逐倉合約，所有已驗證標的都能選多／空及槓桿。舊現貨與原一倍做空不強制轉換，保留獨立介面與原回執。美股與加密貨幣大標、K 線與開／平倉價採 USD，小標顯示 TWD 等值；錢包、保證金、費用和最後損益仍以整數台幣點數結算。

搜尋在獨立兩執行緒工作池執行，不在 HTTP 或 SQLite 寫入交易裡等來源。使用者查詢最多三十個新查詢／分鐘，全域最多四個未完成工作、128 個短期結果；同查詢共用工作，查詢失敗不洩漏上游錯誤。台股依證交所／櫃買公開股票與 ETF 清單辨別 tse／otc，不開放權證；美股經 Yahoo 搜尋核對美國交易所及 EQUITY／ETF；幣種依 Kraken 有效美元交易對，排除法幣。只接受已驗證目錄，不接受使用者指定任意 URL／市場／幣別。選擇標的只加入本人最多二十個自選，不買入、不保留點數。

各人的自選、現貨、舊做空、新合約與待成交會合併成活躍清單；開啟中的部位即使離開頁面也會監看。搜尋得到不代表可立刻成交：必須等行情完整、新鮮且在交易時段。免費來源可能限流，屆時顯示暫停，不借用歷史價成交。

## MIS 盤中保護

伺服器共用單一背景工作，每輪將五檔合併成一個 `getStockInfo.jsp` 請求，目標間隔約 5–10 秒；不因玩家人數增加請求。前端可見交易頁每五秒同步，背景停止。一般交易時段限定台灣時間週一至五 09:00 至 13:30（不含）；遇假日／停牌／資料不全不會靠本機時間推造報價。

每檔要求有效的價格依據、最佳買價 `b`、賣價 `a`、對應正數委買／賣量 `g/f`、上市市場代碼，以及完整來源日期時間 `d/t`。`tlong` 必須與來源日期時間一致（容許一秒格式差）。BBO 的 `-`、0、NaN、無窮值、缺欄、交叉買賣價、重複矛盾標的、未知標的、時間倒退、超過 30 秒或未來超過五秒的報價不成交；不以昨日收盤補價。若來源明確以 `z=-` 表示沒有這一瞬的成交，仍有完整新鮮 BBO 時，可用買賣中間值作**明示的參考價**，source 為 `TWSE MIS 買賣中間參考價`，不冒充成交價；真正的 bid／ask 保留，缺任一方或缺來源時間仍停單。每筆報價還必須在二十秒內成功重新確認。

遺漏／壞資料立即透過獨立 `market_quote_health` 表停止該檔；整個請求失敗則停止全部台股。保留最後有效估值和歷史，待新完整資料恢復；不拿不完整報價平倉或強平。不自動退掉仍未到期的委託，玩家可取消，原到期規則及去重回執維持。原每日收盤報價升級後只能顯示，不能成交；首次 MIS 讀取不會被原每小時排程拖延。

健康狀態使用獨立表，原 `market_quotes` 十二欄不變，避免部署回滾的舊版位置式 INSERT 因增欄失效。前端依伺服器時間和有效期限停用過期按鈕，後端每次接受委託、實際成交及強平仍重新檢查。網路失敗或斷線時不得把本機收取時間冒充來源時間。

## Yahoo 美股保護

固定白名單 AAPL／MSFT／NVDA，由背景工作每輪最多三個並行請求、每請求八秒 socket timeout 與 2 MB 上限；不因訪客增加請求、不在 HTTP／資料庫寫入交易內等網路。正常交易時段約十秒，休市或失敗退到六十秒；部分標的失敗即停止該標的，保留其他有效標的。429／網路錯誤不嘗試替代域名、代理或重試繞過限制。

必須核對 symbol、USD、EQUITY、1m、有效正數價格、`regularMarketTime` 與來源 `currentTradingPeriod.regular` 起迄時間。以來源 Unix 時段處理美國夏令／冬令與提早收盤，不用台灣固定時間推測。時段欄位缺失、來源倒退／未來時間、非正常交易時段、來源成交價超過九十秒、抓取確認超過三十秒、FX 超過三天，全部停止接受與執行成交／強平。相同來源時間反覆抓取不算新價；歷史分鐘線與 `regularMarketPrice` 分開保存，線能畫不代表能成交。

`market_quote_meta` 保存 US 來源交易時段；`market_history` 保存純圖表資料。原 `market_quotes` 十二欄維持回滾相容，US 舊 bid／ask 欄只保存參考價相容值，公開 API 的 US bid／ask 回 `null`，另帶 `execution=reference_trade`；畫面不顯示虛構買賣價。舊 Marketstack 資料只供舊估值，不能再成交；原需 Key／每日排程首次升級即換 Yahoo，不等待一天。

## 舊版四個操作（保留既有現貨／一倍做空）

| 操作 | 意義 | 錢包與資產 |
| --- | --- | --- |
| 買入做多 | 用點數持有現貨，看漲 | 先保留預算，以下一筆 ask 換算份額 |
| 賣出持倉 | 賣掉已有現貨，結束該部分做多 | 保留份額，以下一筆 bid 回點；不會開做空 |
| 賣出做空 · 1 倍 | 建立看跌的點數模擬倉位 | 先鎖保證金，下一筆 bid 決定份額與開倉名目金額 |
| 買回平倉 | 結束指定做空倉位 | 下一筆 ask 買回，退回剩餘保證金加損益 |

以上 bid／ask 適用台股與加密貨幣；美股四個方向均以下一筆有效成交參考價模擬。

1 點＝1 元台幣。份額用固定整數單位表示，最多八位小數，不用浮點數記帳。買入／買回成本向上取整，賣出回點向下取整，每筆誤差不到一點，無額外手續費。現貨單一標的最多一百萬份／成本最多 10^12 點。買單預算最多一百萬點，做空保證金 10–1,000,000 點；同時最多二十筆待成交、二十筆做空倉位。

股票委託七天、加密貨幣委託兩分鐘到期；可以取消。未成交買單／做空單退回原額；賣單解除份額保留；取消或到期的「買回委託」不會關閉已存在的做空倉位，也不會釋放其保證金。

## 一倍做空與強平

這是本站**限損的遊戲點數合約**，不是實際融券服務。[一般做空的概念](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-51)是先賣出、之後買回；本站另外承擔跳空超過保證金的差額，沒有追繳、借券費或真實標的交割。

- 以保證金除以開倉 bid，向下取八位小數份額。名目金額不超過保證金（整點取整時可略低於一倍）。賣出所得鎖在倉位，不能拿去再下注或再開倉。
- 做空淨值＝`max(0, 保證金＋開倉賣出點數－買回成本)`。價格下跌淨值增加，價格上漲減少。淨值計入總資產，不把保證金直接當損失。
- 新有效報價使淨值歸零時強制平倉，最多虧完這筆保證金，不再扣錢包；行情跳空也不產生負餘額。已排隊的買回單取消，避免再買回一次。
- 顯示開倉價、份額、保證金、未實現損益、預估強平價和買回按鈕。預估強平價＝`(保證金＋開倉賣出點數)／份額`；實際判定使用整點成本，可能相差不到一點。平倉／強平有明確結果與歷史紀錄。
- 例如保證金 1,000、開倉價 100、份額 10：80 買回可取回 1,200（損益＋200）；價格跳到 500 時強平退回 0，損失 1,000，不額外向錢包收 3,000。
- 行情過期或公司行動待核對時停止新成交／強平判定，不拿未知價格結算。股票單次漲跌超過 35% 仍依原規則凍結舊估值和交易，待維運核對分割等企業行動；第一版不派股息、不自動換分割股數。

## 記帳、恢復與效能

全部委託、保證金、份額、成交、退款與回執共用同一 SQLite 交易／WriteQueue。每筆操作有 operation_id；同回執重送回同一結果，不同內容回 409。回執先存瀏覽器，斷線或重載後仍可確認原委託，不能繞過不確定操作再扣一次。

總資產＝錢包＋桌上與底池＋存款－貸款＋現貨估值＋買入／開空待成交保留預算＋已開做空淨值。買回待成交不重複加資產。過期行情保留最後已知估值並標示；持倉漲跌／取整差額按每小時累積為 market_value，不列補給流入或牌局輸贏，總資產、排行、管理員與公開資金圖使用同一算法。

單一背景工作抓資料，各供應商最多三個並行（Yahoo 子批次另有最多三個）、八秒 socket timeout、2 MB 上限，網路請求時不持有 DB 交易或 WriteQueue。只有成交／退款／強平使用錢包推播，報價 tick 不喚醒所有牌桌。估值使用既有版本快取（positions／orders／quotes／shorts 四表），價格圖從資料庫依時間索引抽樣。可見交易頁每五秒讀取，切換市場與時間立即重讀；背景停止，回前景／網路恢復會忽略卡住的舊讀取，重新同步。

開關 `POKER_MARKET_DATA=1`，離線測試用 `0`。美股 Yahoo 無需 API Key；已移除舊 Marketstack Key 設定入口。來源輪詢與 UI 查詢均共用既有排程，不增加常駐動畫或全站推播。部署閘道與權限範圍不變。

## 逐倉點數合約

`market_contracts.py` 提供新合約，原 `market.py` 合併總資產、估值與生命週期；原本十二欄 quote schema 不變。`market_catalog.py` 負責動態目錄／搜尋／自選，`market_charts.py` 保存原幣快照與原始 OHLC。

模型參考 [OKX 逐倉線性合約風控](https://www.okx.com/en-gb/help/frequently-issues-of-contracts-for-compulsory-liquidation)及[級距規則](https://www.okx.com/en-us/help/v-tiered-maintenance-margin-ratio-rules)，也核對[幣安名目部位／槓桿說明](https://www.binance.com/en-ZA/support/faq/detail/360033162192)。OKX 公開 BTC-USDT 逐倉 tier API 於 2026-10-28 的前四級維持率為 0.4%、0.5%、0.75%、1.25%，最高槓桿依次 100、66.66、50、40。本站採整數選項，**台幣點數門檻由本站另訂**，不是宣稱股票或所有幣種都有相同交易所合約。

| 同帳號同標的同方向名目點數合計 | 最高整數槓桿 | 維持保證金率 |
| --- | --- | --- |
| ≤1,000,000 | 100 | 0.40% |
| ≤5,000,000 | 66 | 0.50% |
| ≤20,000,000 | 50 | 0.75% |
| ≤100,000,000 | 40 | 1.25% |

可選 1／2／3／5／10／20／25／40／50／66／100 倍，仍受級距限制。方向分開逐倉，拆開同方向訂單不能迴避級距。單筆保證金 10–1,000,000 點，最多二十筆倉位與開倉委託，每人最多二十筆待成交。新參考價導致級距或份額不合時，取消並退回全部保留點數。單筆份額最多十億份，避免極小價格造成資料庫整數溢位。

保證金 M、槓桿 L、原幣價 P、USD/TWD 匯率 F（台股 F=1）：

- 名目金額上限＝M×L；份額 Q＝向下取八位小數的 M×L÷(P×F)。
- 開倉先保留 M＋ceil(M×L×0.05%)，等委託後的新有效來源價才確定 Q，費用按實際名目值進位，多留部分退回。
- 多單未實現損益＝Q×(目前原幣價−開倉原幣價)×目前有效 F；空單正負相反。原幣價不動，單純 FX 改變不會捏造標的價差獲利。
- 權益＝M＋未實現損益；維持要求＝目前名目值×級距維持率；估計平倉費＝ceil(目前名目值×0.05%)。
- 權益 ≤ 維持要求＋估計平倉費時觸發強平。一般平倉退回 max(0, floor(權益−平倉費))；完整損益再扣原開倉費。
- 預估強平價（原幣）多單＝(Q×開倉價−M/F)÷[Q×(1−維持率−費率)]；空單＝(Q×開倉價＋M/F)÷[Q×(1＋維持率＋費率)]。實際依精確有理數與整點費用判斷，匯率與同向部位級距改變時估計會改變。

**與交易所的差異明示**：本站沒有交易所訂單簿／指數標記價，以來源有效參考價模擬開平與風控；首版不做高階部分減倉／ADL，強平會完整關閉該筆逐倉、返還 0，不追扣其他錢包，跳空超損由遊戲機制承擔。開／平各收 0.05%，資金費率目前 0%，不假裝接入了即時資金費率。股票照來源正常時段，休市、缺資料、過期或公司行動待核對都不成交／強平。不是實際股票期貨、融券或交易所永續交易。

所有點數入帳、份額、費用、取消、逾期與強平都共用 WriteQueue／SQLite 交易與原操作回執表。同回執跨端點內容不一致回 409，重送先回原結果，不再保留點數。下單前瀏覽器先保存回執；斷線重載後確認原委託。強平會取消已排隊的平倉單。總資產納入開倉保留預算與合約淨值；估值、取整與費用以每小時 market_value 記錄，不算外部補給或牌局輸贏。

部署暫停期間阻止新合約開／平委託，取消及既有回執仍可重送。首次部署驗證完成、解除暫停前不會建立新合約，失敗可回退。**合約開放後維運不得回退至不認得 market_contracts 的舊版**，應部署仍保留合約記帳／監看能力的修復版本，不還原正式資料庫去丟失點數交易。

## 真實 K 線與分析工具

K 線使用 [TradingView Lightweight Charts 5.2.1](https://tradingview.github.io/lightweight-charts/docs) 的固定本機套件，只有交易頁需要畫 K 線才載入，不連執行期 CDN。Apache 授權與 NOTICE 隨站台提供，`scripts/vendor-market-chart.cjs --check` 核對套件與本機檔案一致。

Yahoo 提供股票原始分鐘 open／high／low／close／volume；Kraken 提供美元交易對原始 OHLC。圖表時間軸與查價統一使用台灣時間，保留原 UTC epoch，不平移或造假來源時間。原幣 `market_observations` 與純圖表 `market_candles` 分開保存，不把當天匯率倒算成過去原幣價，也不讓歷史 K 線觸發成交。無效 OHLC、未來時間及重複矛盾點略過；未收盤 K 線標明並可更新，已完成來源 K 線不改寫。保留八天純圖表資料，提供 1 分／5 分／15 分／1 小時／日 K 聚合，一次最多五百根；聚合時包含顯示範圍內第一根 K 棒的完整時段，只有每分鐘樣本連續且齊全才標示「已收盤」，缺樣本標「取樣未齊」並列出觀測分鐘數。股票休市的日 K 也按實際分鐘資料標示，不補假價；缺 OHLC 時只畫真實觀測線。

可縮放／拖曳、鍵盤查 OHLC、均線20／EMA20／布林20、兩點趨勢線；畫線以帳號／標的／週期儲存在本機，最多十二條。左右鍵查價；畫線時上下鍵調整端點價、Enter 設點、Esc 取消，縮放與重設另有按鈕，並保留 OHLC 數值表。指標不足二十根會說明，不補假樣本。分析／畫線不下單、不改任何行情或點數。

TW、US、CC、FX 與歷史線各有獨立有界背景工作，來源 timeout 不把其他市場的報價卡住。所有網路工作均在 SQLite／WriteQueue 之外；可見交易頁五秒同步，背景停止，不把報價 tick 推給每張遊戲牌桌。
