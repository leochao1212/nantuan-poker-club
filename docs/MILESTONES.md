# 遊戲里程碑與稱號效果

每種現行牌桌遊戲都有三階里程碑，使用已結算、確實投入籌碼的有效局數。歷史紀錄會回補；只觀戰、未下注略過，以及礦區／爬塔未選格就退款，不計入。只計本人，每局至多一次，不要求獲利。歷史修正／刪除／交易回滾會修正進度；已領取的稱號是永久收藏。

| 遊戲 | 三階有效局數 |
| --- | --- |
| 德州撲克、大老二 | 50／250／1,000 |
| 台灣麻將 | 20／100／500 |
| 21 點、歐式輪盤、百家樂、拉霸、尋寶礦區、爬塔、Dice 骰寶、射龍門 | 100／1,000／10,000 |

達標後到「補給任務 → 遊戲里程碑」手動領取，拉霸一萬局為「萬轉傳奇」。各階只解鎖專屬稱號，不額外發放點數，也不能直接購買。領取沿用 operation_id 回執，重試不重複取得獎勵。可到收藏或個人設定裝備。

## 單一稱號效果

只計裝備中的一個稱號，收藏數量不疊加。每日補給以 1,000 點為基礎，最多 +2%（1,020 點）；每小時補給以 200 點為基礎，最多 +10%（220 點）。依領取當下裝備計算，加成部分採整數無條件捨去。例如每日 +0.75% 可領 1,007 點。

里程碑第 1 階：每小時 +1%；第 2 階：每日 +0.25%、每小時 +2%；第 3 階：每日 +0.5%、每小時 +3%。不影響會所、員工任務、遊戲抽牌、命中率、派彩、銀行利率或交易。

每日仍以台灣時間換日，每小時仍從成功領取起冷卻 60 分鐘；換裝、取消裝備、買新稱號、重整或重試都不會重置資格，也不會補發先前領取與新稱號之間的差額。金額由伺服器使用 basis points 計算並寫入原補給流水；不另開可重複領的加成獎勵。

本版以 title_supply_perks_v2 一次性移轉：按原稱號結清更新前已累積的會所收益，之後恢復原本建築／裝潢的速度與容量。已存超過新容量的收益不刪除，先停止新增，領取後繼續累積。初始化重試不重複結算；舊稱號持有權、補給流水及冷卻時間全部保留。

## 架構與驗證

- result_stats.py：result_facts 的交易內觸發器維護 player_game_totals；一次性回補舊歷史。日常讀取只查本人遊戲總數，不重掃歷史 JSON。
- rewards.py：固定稱號目錄、里程碑領取、伺服器價格與效果上限；public profile 沿用原裝備來源。
- wallet.py：伺服器補給金額、換日與冷卻唯一性，交易內鎖定領取時的稱號。
- schema_migrations.py／clubhouse.py：一次性結清舊稱號收益，保留超容量存額，後續會所不再受稱號影響。
- static/club.js：補給頁的遊戲進度、領取與收藏效果；沿用 night.css 與現有頭銜樣式，不新增圖片下載。

測試涵蓋舊歷史回補、所有 11 款遊戲、零投入／退款排除、修正刪除回滾、1 萬局、領取與購買重試、舊價格拒絕、單一裝備不疊加、補給金額與整數捨去、並行發送、換裝不重領、舊收益結清與超容量保留、資料庫初始化重試。Chromium／WebKit 的手機與桌機流程測試 320／393／768／1366 寬度，實際領取、購買、裝備並確認錢包及效果。
