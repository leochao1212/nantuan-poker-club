# 遊戲里程碑與稱號效果

每種現行牌桌遊戲都有三階里程碑，使用已結算、確實投入籌碼的有效局數。歷史紀錄會回補；只觀戰、未下注略過，以及礦區／爬塔未選格就退款，不計入。只計本人，每局至多一次，不要求獲利。歷史修正／刪除／交易回滾會修正進度；已領取的稱號是永久收藏。

| 遊戲 | 三階有效局數 |
| --- | --- |
| 德州撲克、大老二 | 50／250／1,000 |
| 台灣麻將 | 20／100／500 |
| 21 點、歐式輪盤、百家樂、拉霸、尋寶礦區、爬塔、Dice 骰寶、射龍門 | 100／1,000／10,000 |

達標後到「補給任務 → 遊戲里程碑」手動領取，拉霸一萬局為「萬轉傳奇」。各階只解鎖專屬稱號，不額外發放點數，也不能直接購買。領取沿用 operation_id 回執，重試不重複取得獎勵。可到收藏或個人設定裝備。

## 單一稱號效果

只計裝備中的一個稱號，收藏數量不疊加。只影響會所被動收益與收益儲存容量，不影響員工任務、補給、遊戲抽牌、命中率、派彩、銀行利率或交易。產速效果最高 2%，儲存容量最高 10%。稱號不改變原有裝潢速度規則。

里程碑第 1 階：容量 +1%；第 2 階：產速 +0.25%、容量 +2%；第 3 階：產速 +0.5%、容量 +3%。

所有加成都以 basis points 計算整數收益單位。裝備／更換／卸下之前，先依原稱號結算已累積收益；新效果從當下起生效。降低容量時，已累積收益仍保留，超過新容量期間暫停新增，領取後再繼續累積。既有裝備在版本升級時只結算舊規則，不回溯加倍；初始化可重試。

## 稱號商店價格

既有持有權與裝備保留，不補扣差額。購買使用伺服器價格與 expected_cost 確認，舊分頁、舊價格或不正確格式回應 409，不會默默改用更高金額扣款。回執與持有唯一鍵避免重送重複扣款。

## 架構與驗證

- result_stats.py：result_facts 的交易內觸發器維護 player_game_totals；一次性回補舊歷史。日常讀取只查本人遊戲總數，不重掃歷史 JSON。
- rewards.py：固定稱號目錄、里程碑領取、伺服器價格與效果上限；public profile 沿用原裝備來源。
- clubhouse.py：整數收益計算、舊收益結清、效果切換及升級時的容量保護。
- static/club.js：補給頁的遊戲進度、領取與收藏效果；沿用 night.css 與現有頭銜樣式，不新增圖片下載。

測試涵蓋舊歷史回補、所有 11 款遊戲、零投入／退款排除、修正刪除回滾、1 萬局、領取與購買重試、舊價格拒絕、單一裝備不疊加、收益不回溯、超容量保留、資料庫初始化重試。Chromium／WebKit 的手機與桌機流程測試 320／393／768／1366 寬度，實際領取、購買、裝備並確認錢包及效果。
