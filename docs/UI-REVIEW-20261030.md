# 全站介面檢查與改善

本次保留牌室既有綠金美術、遊戲規則與金流，只調整導航、層級與閱讀順序。變更在 `design/club-polish-promo`，尚未部署正式站。

## 已修正

- 大廳原本先顯示大幅樂透卡、再顯示銀行入口，才出現開桌主操作。現在先顯示頁面名稱與開桌主視覺，再用精簡的樂透／銀行／交易入口列銜接牌桌。桌面同一視窗下，主視覺頂端約從 493px 提前至 220px。
- 桌面側欄帳號區的 flex 子項無法縮小，造成橫向捲動、登出按鈕擠出。改為可縮小的文字區，長帳號截斷、按鈕完整保留；實測側欄 scrollWidth 203px、外框 204px。
- 大廳建立包廂、頁面捷徑、銀行跳轉與樂透電腦選號改為清楚的次要按鈕。保留主操作的金色美術，不改遊戲內的下注控制。
- 樂透明示已選數量，未滿 5 號時顯示還需要選幾號；截止、額度已滿及餘額不足分別說明原因。
- 手機樂透縮小頂部主視覺，將長規則改為可展開區塊，並提供「查看我的彩券」捷徑。捷徑使用頁內捲動與焦點，不改變 SPA 路由；桌面預設展開獎項表。
- 窄手機頂部移除重複的銀行按鈕，保留可點擊的餘額入口，避免語音與個人按鈕被擠出。
- 樂透的按鈕、選號、金額與資訊配色回到現有牌室的綠金系統；獎項欄位避免單字擠成直排。

## 檢查範圍與證據

`tests/browser/layout.cjs` 檢查大廳、排行、成員、會所、補給、收藏、個人頁、銀行、轉帳、後台，以及德州、大老二、21 點、麻將、輪盤、百家樂、拉霸、尋寶、爬塔、骰寶與射龍門。Chromium / WebKit 共 21 個頁面、314 個視窗檢查通過；最後按鈕細修後，另跑大廳／銀行／補給共 42 個視窗通過；窄螢幕頂部修正後，大廳再驗證 14 個視窗通過。包含 320px 窄手機、橫向、平板與桌面。

`tests/browser/lottery.cjs` 的手機／桌面購票、重載重送、扣款唯一性、開獎顯示與溢位檢查通過。未改後端金流或遊戲機率，因此沒有重跑與本次 UI 無關的整套 Python 測試。

另以實際 Chrome 核對大廳、側欄和樂透。最初從截圖懷疑全站字型未套用；實際 computed style 證實後段樣式已套用正確字型，因此沒有做不必要的字型修改。UI 技能對按鈕層級的兩次資料搜尋沒有直接適用結果，本次層級調整依現有畫面與一般介面設計原則判斷。

完整測試截圖在忽略版本控制的 `artifacts/layout/` 與 `artifacts/lottery/browser/`。動畫、牌桌美術與操作契約沿用原版。此輪不宣稱已對所有遊戲所有可能狀態進行人工審查。
