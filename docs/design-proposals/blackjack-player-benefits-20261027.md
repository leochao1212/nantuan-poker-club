# 二十一點玩家優待

本次依站長要求，讓所有玩家更容易獲利，並提供管理員簡單調整。只改結算優待，保留六副牌公平洗牌、連續牌靴及S17；不依帳號、輸贏或目前手牌更換下一張牌。這是本站公開娛樂規則，與標準賭場21點不同。

## 設定與生效

後台路徑：管理員 → 下注上限與遊戲設定 → 21點 → 玩家優待快捷設定。

| 快捷設定 | 普通同點轉為玩家勝出 | 爆牌全額退注 |
| --- | ---: | ---: |
| 關閉 | 0% | 0% |
| 輕鬆 | 50% | 25% |
| 歡樂 | 100% | 50% |

兩項都能獨立自訂0–100%，使用既有預覽、版本鎖、儲存回執與設定變更記錄。快捷設定不變更原普通／Blackjack／五張未爆倍率及牌靴副數。儲存後下一局生效，所有玩家一致，牌桌顯示當局比例。

既有正式站首次更新時，以一次性有記錄的設定移轉啟用輕鬆50%／25%；`game_settings_migrations`保存前後值及版本，後台標示系統移轉。後續重啟不覆寫管理員選擇；已存在任一新欄位也保留其自訂值。全新安裝預設關閉。進行中的舊局及既有收據沿原快照，不追溯改派彩。

## 結算順序

1. 玩家爆牌：按`bust_refund_bps`獨立判定，成功返還該手全部實際下注，淨輸贏0，顯示「爆牌保護・本手全額退注」。加倍返還加倍後下注，分牌各手分別判定，不重複返還整位玩家總下注。
2. 莊家自然Blackjack：沿原規則，雙方自然Blackjack和局；此類和局不享同點轉勝。
3. 玩家五張未爆、玩家自然Blackjack、普通勝出：沿原派彩，不額外疊加優待。
4. 其餘普通同點：按`tie_win_bps`獨立判定，成功按普通勝局倍率派彩，顯示「同點優待・玩家勝出」；未觸發仍退本金和局。
5. 其餘普通落敗：沿原規則。

0%不抽優待亂數，100%直接成功；中間比例以安全亂數判定。每手保存`benefit={kind,rate_bps,triggered}`及原有payout。優待在全部取牌完成後計算，不改牌、補牌或牌靴。退注不算勝局；同點轉勝才增加勝出機會。

原回執重送不重抽、不再派彩；當局規則、結果、玩家統計與出桌點數共同提交。未觸發時保持原結果。莊家備付沿原最高分牌／加倍派彩預留，退注只返還已收下注，不額外產生獎勵。

## 收益驗算

對一手下注B、普通淨贏倍數W：原普通和局的期望新增返還為`同點轉勝率 × B × W`；原爆牌的期望新增返還為`爆牌退注率 × B`。二者不減少其他原本派彩，牌序與決策固定時，玩家期望收益不會因啟用而降低；整體勝率和返還率仍取決於打法、倍率及牌靴，不是固定宣稱的RTP。

以[可重現配對模擬](../../scripts/bench-blackjack-benefits.py)跑20,000局／模式，單人、每局新六副牌、硬17／軟18停牌、不加倍不分牌，兩種模式逐局使用完全相同的牌：

| 結果 | 關閉 | 輕鬆50%／25% |
| --- | ---: | ---: |
| 勝局 | 8,438 | 9,366 |
| 勝出率 | 42.19% | 46.83% |
| 和局／退注 | 1,885 | 2,289 |
| 輸局 | 9,677 | 8,345 |
| 投入 | 2,000,000點 | 2,000,000點 |
| 返還 | 1,962,650點 | 2,188,650點 |
| 實際返還比例 | 98.1325% | 109.4325% |

新增928局同點轉勝、1,332手爆牌退注，逐局牌面完全一致且籌碼守恆。此為固定策略與種子下的隔離模擬，包含本站五張未爆規則；不是正式連續牌靴／各種打法下的固定理論RTP，也不是保證每位玩家或每次遊玩獲利。
