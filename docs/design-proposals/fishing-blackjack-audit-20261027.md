# 捕魚修正與二十一點公平性核對

日期：2026-10-27。修正前正式版本為ddb280a；發布與測試結果以對應PR及Actions紀錄為準。

## 捕魚：已確認的問題與處理

- 舊魚圖以等分格裁切，魚鰭／長吻會越界，鄰格殘片也會出現。改為16種生物各自六姿勢，完整魚體自適應框，96框均驗證沒有不透明鄰格重疊。移除舊四張游動圖集。製作時縮圖轉WebP，不在客戶端去背。
- 舊畫面依螢幕拉伸魚身，伺服器仍以原世界橢圓判定；現在相同比例、相同轉向、相同凍結時間，點按與繪圖使用同一座標轉換。
- 高價炮先前只改點數及獎金，新版同時擴大捕網、提高彈速；雷射可連鎖光束內最多三尾普通魚，總倍率一起列入捕獲機率，僅記一發扣點及一筆總派彩。
- 六個房間原先高度相同，改分三種海底場景、魚群配置及主要Boss；Boss每4秒增加公開倍率，捕獲時確定金額。捕網、命中閃光、雷射及金幣飛回對應炮台均有動畫。
- 魚場推播若保持OPEN卻不再來事件，原先只停止發射，沒有重建。現在超過6秒主動重建，舊連線事件不能覆寫新狀態；背景／重連均停止自動射擊。
- 超過40秒釋出座位後，回來先嘗試重新入座，滿桌保留換房／重入按鍵；主動觀戰不強制入座。同魚場更換裝備即更新主射擊鍵美術。

捕獲模型維持公開的條件點數期望，預設95%，包含連鎖及寶藏；不是每一局或每位玩家保證返還95%。落空仍扣點，會再拉低整體返還。魚倍率越高，單次捕獲率越低，連續未捕獲屬可能結果；沒有累積到必定捕獲的血量。高價炮增加幾何命中範圍，不另外增加隱藏抽取次數。完整公式見[漁港規格](../FISHING.md)。

## 二十一點：歷史資料與算法

以正式資料庫唯讀交易核對2,045局、2,322個玩家手牌：莊家自然Blackjack為96局（4.6944%），玩家自然Blackjack為115手（4.9526%）；同牌桌最長連續莊家Blackjack為2局。新六副牌任取兩張的理論自然Blackjack率為24×96／C(312,2)＝4.74895%。牌靴用過後的條件機率會隨剩餘牌改變，不能將所有牌局視為完全獨立的新牌靴。

這批歷史局合計下注10,023,370點、返還10,127,838點，實際返還101.04%；這是不同玩家、不同下注策略及歷史設定的合計結果，不是未來的保證返還率，也不能代表每位玩家都獲利。

重算全部已存玩家派彩與逐手結果，未發現差異；檢查莊家摸牌過程，未發現17點後繼續要牌。對有牌靴ID的86副牌靴，核對9,762張已發牌，未發現同一張牌超過設定副數或重複局序。較舊紀錄沒有牌靴ID，不能由歷史公開狀態完整重建其私有剩牌順序；因此不宣稱逐張證明所有舊洗牌結果。

洗牌為`secrets.SystemRandom().shuffle`，六副52張（312張）一次洗勻，從同一私有牌靴尾端逐張取牌；每輪依座位發玩家再發莊家，共兩輪。剩78張或不足以安全支援下一局分牌／補牌時，於開下一局前換牌靴，局中不重洗。沒有依帳號輸贏切換洗牌算法或挑牌。

現行規則：莊家軟17停牌；兩張A＋10點牌才是自然Blackjack，預設淨贏3:2；一般勝出1:1，雙方自然Blackjack和局。本站另有「五張未爆」淨贏2:1，與一般標準21點不同；分牌後21點不算自然Blackjack。管理員倍率依開局時快照結算。

本次只抽出一致的自然Blackjack判斷並改善標示，未調整洗牌、自然Blackjack出現率或莊家結果。輸錢本身不足以證明亂數失常，且正確規則仍可能有莊家優勢及短期連敗。

規則參照：[Bicycle官方Blackjack](https://bicyclecards.com/how-to-play/blackjack/)、[Wizard of Odds概率問答](https://wizardofodds.com/ask-the-wizard/blackjack/probability/)。
