# 釣魚固定參考與改版對照

街機方向已依使用者指定改成[黃金捕魚場](fishing-golden-carnival.md)；以下Ocean King部分保留為上一版設計歷史。

固定檢視版本：2026-10-26。參考公開可觀察的遊戲回合、構圖與動畫，不宣稱取得未公開原廠數值／原始碼。

## 休閒：Fishing Clash（Ten Square Games）

依據：[官方操作](https://tensquaregames.helpshift.com/hc/en/3-fishing-clash/faq/42-casting-the-line-and-catching-fish/)、[官方商店與實機圖](https://play.google.com/store/apps/details?id=com.tensquaregames.letsfish2)。

- 第一人稱海灣占滿畫面，魚竿與釣線在前景；畫面內右下拋竿／提竿／收線，魚餌在左下。
- 咬鉤後以頂部橫向張力條控魚：按住張力上升、放開下降；支援收線滑桿。張力過高斷線、過低脫鉤，中心區增加Combo與分數。
- 上鉤切近水面／水下搏魚鏡頭，魚隨收線靠近；成功以大魚特寫、尺寸、星等、分數與獎勵結算。
- 舊版竿沿舊控魚規則完成。新回合魚餌對應魚種與精力成本；本站保留每日精力及虛擬點數制度，不複製原作商店與付費系統。

## 街機：IGS Ocean King 3: Monster Awaken

依據：[IGS產品線](https://www.igs.com.tw/jp/about/39/)、[發行商玩法及畫面](https://americanalphainc.com/product/ocean-king-3-monster-awaken/)、[實機影片](https://www.youtube.com/watch?v=KaBW59PVxog)。

- 俯視海底共用畫面，六人砲台沿四周；中央魚群成隊游過，特殊魚與大型魚事件進場。
- 指向／觸控魚場射擊，獨立鎖定與自動連發，砲彈碰撞展網、捕獲飛出點數；單次點按不多發、放開及背景停止。
- 黃金蟹、章魚、電鰻、海龍對應範圍／觸手／連鎖／爆破效果；連鎖魚亦由伺服器唯一捕獲，不由動畫自行派彩。
- 未公開派彩使用本站公開條件派彩基準：特殊魚依本次包含連鎖的總倍率計算捕獲機率，成功才一起結算，避免額外獎勵悄悄改變基準。

## 視覺與操作規格

主體是全畫面遊戲舞台，魚簍、圖鑑與規則改由面板開啟，移除舞台旁表單。手機按鈕至少48px並保留8px間距，橫向更寬魚場；桌機以同一操作布局擴展。海水藍#087ca8、深海#032d48、珊瑚#ee734b、金色#f3c95e、字白#f5fbff；字體沿用系統繁中字，數字tabular。

原創場景及特殊魚圖集以內建ImageGen產生，再轉WebP保留alpha。魚尾／釣竿／水面／捕網等由Canvas按事件動畫，最多30fps、減少動態降至20fps；伺服器裁決、錢包回執與魚場SSE沿既有分流機制。
