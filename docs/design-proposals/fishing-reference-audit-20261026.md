# 黃金捕魚場實玩對照與重做規格

日期：2026-10-26。已依本次核對實作v5炮價派彩、寶藏與動畫；部署結果以PR及CI紀錄為準。下文「目前／正式站」比較表記錄重做前PR #29的狀態。

## 先前實作的問題

上一版[攻擊模組](../../fishing_power.py)將10／100／1,000點砲彈拆成1／10／100次抽取，派彩為10×魚種倍率×成功次數。這是本站自訂的Binomial攻擊模型，沒有原作依據。先前驗證了這套模型的期望與記帳，但沒有驗證它與指定參考遊戲的玩法相同。

例如1,000點砲打20倍魚，一份成功只返還200點，成功數決定最後金額。玩家看到的20倍不能直接換算成自己當前砲彈的捕獲價碼，這就是目前不直觀的原因。修改時不能只把公式的10替換成1,000，還保留100次抽取；這會把期望派彩重複放大。

## 本站下一版的結算建議（不是已核實的原作公式）

以玩家看得懂的「當前炮價×魚種倍率」作普通捕獲的明確契約。例如100點砲、20倍魚，普通捕獲總返還2,000點。圖鑑及鎖定提示同時顯示倍率與目前炮價下的金額；切換炮價立即更新預覽，已射出的砲彈保留射出時快照。

特殊魚另保存當場魚價／倍率範圍；寶箱與Boss獎勵另有事件結果、金幣／道具種類、次數及金額明細。結算時展示普通捕獲、事件獎勵與最終總返還。原作完整魚種表、寶箱獎表／觸發條件仍需依遊戲內說明核對，不填入猜測的機率。

攻擊力、武器能力、捕獲判定與獎勵需要一併重設；移除現有每10點一次抽取的派彩方式。不把「炮價變大」自行等同於原廠捕獲率線性增加，也不宣稱原作有共享固定血量。本站若需要額外的強炮捕獲優勢，需在公開規則與全部獎勵期望中一起設計。

## 實作與驗收順序

1. 經典四人場：炮台旁操作、魚種價目預覽、按當前炮價結算；核對同一魚種在10／100／1,000點的金額，與原回執重送。
2. 一套完整寶箱／特殊魚Bonus：確實觸發、保存事件、展示獎表與過程、領獎只一次；斷線／重進仍能回到未完成事件。不要用一張圖片或通用連鎖冒充獨立玩法。
3. 依實玩畫面逐項校正魚的大小、密度、動作、炮台比例、彈道、捕網、金幣與獎勵節奏；以手機橫向及桌機可操作錄影對照。
4. 在前述流程正確後擴充其他海域、Boss、道具取得與養成。捕獲機率及RTP另列本站規則，包含全部Bonus成本／獎勵，不以畫面相似度代替驗算。

本次只將可證實的流程特徵用於原創實作。炮價×倍率契約、捕獲設定、寶藏池與道具配額均是本站設定，不宣稱原作內部數值相同；完整公式與相容策略見[現行漁港規格](../FISHING.md)。
