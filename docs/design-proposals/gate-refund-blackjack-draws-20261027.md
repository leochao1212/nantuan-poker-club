# 射龍門免扣點保護與二十一點取牌核對

## 射龍門 v4：保留柱牌，觸發即免扣點

先前v3以50%機率將第一張柱牌作廢，按原牌序補至非柱牌，補出的牌仍可能在門外而扣一注。新版依本次要求改為：抽到柱牌後，按當局快照的保護率獨立判定；成功保留原牌，只消耗這一張，本局扣點、派彩及淨輸贏全為0。普通撞柱原扣兩注、對子撞柱原扣三注，觸發時全部免除；沒有先扣點再要求領回。

結果以持續顯示的提示列出當局玩家暱稱、「本局扣點0」與免除金額；`protection_event`保存玩家ID、當局暱稱、原柱牌、當局保護率與免除點數。同桌觀戰快照、牌局歷史與操作重送都使用同一結果。未通過保護判定則明確標示「保護未觸發」。

50%是每次抽到柱牌後獨立判定，不代表每兩次一定保護一次，也不是每一局有50%免費。畫面會保留實際抽到的柱牌，因此柱牌本身的出現率沒有降低；「撞柱扣點率」才扣除保護成功的情況。舊v3已開局與歷史結果仍依原規則／凍結報價處理，不改寫已完成交易。

管理員仍可調整0–100%保護率，只在新局生效。保留原命中含本金倍率，不降低派彩。若剩牌N、其中柱牌m、命中牌w、保護率r、未保護撞柱扣款倍數L：

- 命中率：`w/N`。
- 原始柱牌率：`m/N`；免扣點率：`r*m/N`；撞柱扣點率：`(1-r)*m/N`。
- 每注期望實扣倍數：`1+(L-1)*m/N-L*r*m/N`。
- 本注理論返還率：`命中率 * 向下取整後含本金派彩 / 每注期望實扣點數`。

例：新牌靴門柱5與9，剩50張，12張可中、6張柱牌，下注100點、保護50%、保護前派彩基準97%。命中返還仍為452點；原始柱牌率12%、保護免扣點率6%、撞柱扣點率6%、本注理論返還率108.48%。這是以實際扣款為分母的長期比率，可能超過100%，不是單局保證獲利。未保護時仍須預留普通兩注／對子三注；100%保護只需預留一注。

## 二十一點：兩張Blackjack與多張21點分開核對

2026-10-27以正式資料庫唯讀、匿名彙總核對2,047局、2,324個玩家手牌：

| 莊家結果 | 局數 |
| --- | ---: |
| 兩張自然Blackjack | 96 |
| 三張21點 | 84 |
| 四張21點 | 24 |
| 五張21點 | 4 |
| 六張以上21點 | 0 |

五張21點為4/2,047，約0.20%，不是自然Blackjack。所有已存莊家補牌序列均未發現17點以上仍補牌。規則仍為軟17停牌；五張湊21可勝過一般20點，但不能壓過玩家兩張自然Blackjack。本次補上明確的「5張湊成21點・非Blackjack」標示及確定牌序的結算測試。

87副可完整追蹤起點的牌靴，涵蓋1,648局，未查到剩牌計數負值或局序缺口。按當時剩牌及實際玩家取牌，對830個莊家需補牌的局面逐一枚舉後續S17補牌概率：多張21點的條件期望合計96.18次、實際89次；五張21點條件期望3.97次、實際3次。未把這830局的期望拿去與全部2,047局的次數混比。

## 十點牌連在一起

T、J、Q、K都算十點；一副52張有16張，六副牌為96/312＝30.77%。在新牌靴僅移去兩張十點牌、暫不計其他已知牌時，下一張仍為十點牌的機率為94/310＝30.32%，不是10%。20點後再要牌，只有24張A不會爆牌；此簡化局面的爆牌率為286/310＝92.26%。實桌機率須按當時剩牌與其他已發牌計算。

歷史上163手起手為兩張十點牌，其中13手又繼續要牌；7手第三張仍為十點牌，12手因這張牌爆牌。這個小組的十點牌比例確實偏高，不能隱去；13次樣本也不足以單獨證明洗牌被操控。可完整還原剩牌的其中8次，有6次第三張十點，按各次剩牌的期望合計2.49次；同樣是小樣本，應保留觀察，不能宣稱完全排除異常。

較大的可追蹤相鄰取牌樣本中，十點牌後有2,918次可確認的下一張牌，其中912次仍為十點牌（31.25%）；逐次依剩牌計算的期望887.54次（30.42%）。未見此大樣本有明顯的系統性十點聚集。分牌造成無法完整還原中間順序的片段不當作已知相鄰序列；399個沒有可還原完整牌靴起點的舊局不加入剩牌條件機率分析。

洗牌仍是安全亂數對六副牌洗牌後，從同一私有牌靴依序取牌；沒有依帳號、目前點數或前兩張20點去挑下一張牌。本次不調整洗牌、牌值權重或莊家取牌概率。既有派彩重算核對見[上次稽核](fishing-blackjack-audit-20261027.md)。本文件只列匿名彙總，不含帳號、逐局個人牌面或時間清單。
