# 今晚，差你一個。

楠團牌室 30 秒宣傳影片，1920×1080、30 fps、H.264 / AAC 立體聲。影片是原創 Canvas 動畫與程式合成音樂，使用專案自己的遊戲美術。畫面中的樂透號碼為示意，影片內有標示；介面片段是為宣傳重新構圖的視覺展示，不是玩家交易錄影。

## 原創製作簡報

為朋友專用的虛擬點數牌室做一支 30 秒橫式影片。主題為「今晚，差你一個」。以深綠、象牙白和籌碼金建立統一視覺；利用籌碼的圓、撲克牌的矩形與樂透號碼球連接場景。前段以邀約打開，中段展示熟悉的遊戲和個人會所，後段帶出每日樂透，收在品牌與網址。文字讓觀眾有閱讀時間，避免連續閃爍。音樂為 120 BPM 原創電子／鍵盤節奏，不使用第三方錄音。輸出可逐格重現的來源、分鏡與 MP4。

| 時間 | 內容 |
|---|---|
| 0–4 秒 | 籌碼聚攏，「今晚，差你一個。」 |
| 4–9 秒 | 遊戲大廳與三個遊戲卡片 |
| 9–14 秒 | 牌桌與發牌，「好牌值得等。朋友不用等。」 |
| 14–19 秒 | 會所展示與升級體驗 |
| 19–24 秒 | 每晚 21:00 朋友樂透、100 點／注 |
| 24–27 秒 | 四款遊戲節奏剪輯 |
| 27–30 秒 | 品牌、網址、純虛擬點數說明 |

## 重製

在專案根目錄執行，需已有 Playwright Chromium、FFmpeg、Python 與 NumPy：

```sh
node media/promo-20261030/render.cjs --preview
node media/promo-20261030/render.cjs
python media/promo-20261030/preview.py
```

輸出為 `artifacts/promo-20261030/nantuan-friends-30s.mp4`。預覽服務只在 `127.0.0.1:8880` 提供成片；不提供專案、資料庫或環境檔。`film.html` 可直接開啟並播放無聲動畫預覽。輸出使用 900 個獨立時間影格，非螢幕錄影；音樂來源為 `audio.py`，隨機噪聲採固定種子。
